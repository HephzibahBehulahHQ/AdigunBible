# AdigunBible

**One edition. Scripture in a new generation's language.**

AdigunBible is the original Gen Z Bible edition by Hephzibah Behulah Evangelism. Its verse-by-verse writing uses energetic Gen Z language, slang, expressive punctuation, and emojis throughout while preserving the meaning and flow of each verse. The Gen Z Bible website is a style reference; AdigunBible uses original wording.

## Reading progress

- Genesis 1 — 31 verses rewritten to the current AdigunBible voice and validation rules.
- Genesis 2–12 — existing drafts need review and rebuilding to the current rules.
- Genesis 13–50 — not yet written.

The reader shows chapter structure without inventing Scripture for chapters that have not yet been reviewed.

## Website

GitHub Pages publishes the root `index.html`. Scripture content remains in working branches until every verse in all 66 books passes the current AdigunBible rules and whole-corpus validation gate.

## Editorial rules

- Keep AdigunBible as the only Bible edition in the product.
- Preserve verse numbering, meaning, speaker, sequence, and context.
- Write original wording; do not copy another Bible's text or assets.
- Mark incomplete chapters clearly and never label them complete.

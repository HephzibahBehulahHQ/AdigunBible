# AdigunBible

**One edition. Scripture in a new generation's language.**

AdigunBible is the original Gen Z Bible edition by Hephzibah Behulah Evangelism. Its verse-by-verse writing uses clear conversational language, natural slang, expressive punctuation, and emojis where they fit the passage. The Gen Z Bible website is a style reference; AdigunBible uses original wording.

## Reading progress

- Genesis 1 — all 31 verses published.
- Genesis 2 — all 25 verses published.
- Genesis 3 — all 24 verses published.
- Genesis chapters 4–50 — editorial work in progress.

The reader shows chapter structure without inventing Scripture for chapters that have not yet been reviewed.

## Website

GitHub Pages publishes the root `index.html`. The repository's `CNAME` file sets the custom domain. Content slices are merged progressively so each reviewed chapter can publish as it is ready.

## Editorial rules

- Keep AdigunBible as the only Bible edition in the product.
- Preserve verse numbering, meaning, speaker, sequence, and context.
- Write original wording; do not copy another Bible's text or assets.
- Mark incomplete chapters clearly and never label them complete.
